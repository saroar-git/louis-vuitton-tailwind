# Louis Vuitton – Frontend Website (Demo)

This is a **responsive frontend website** inspired by **Louis Vuitton**, built using **basic HTML** and **Tailwind CSS**.  
The project focuses on clean layout, responsiveness, and simple multi-page navigation.

> ⚠️ **Disclaimer:**  
> This project is created for **educational and practice purposes only**.  
> It is **not affiliated with, authorized, or endorsed by Louis Vuitton**.

---

## 🌐 Pages Included

The website contains **three (3) main pages**:

1. **Home Page**

   - Landing section
   - Brand-focused UI
   - Navigation bar

2. **Heritage Page**

   - Displays brand heritage and legacy content
   - Accessible from the navigation menu

3. **Checkout Page**
   - Cart / checkout layout
   - Accessible via the cart icon

---

## 🔗 Navigation Behavior

- Clicking the **Louis Vuitton logo** → redirects to **Home page**
- Clicking **Home** → redirects to **Home page**
- Clicking **Heritage** → redirects to **Heritage page**
- Clicking the **Cart icon** → redirects to **Checkout page**

Navigation works consistently across all pages and screen sizes.
